2.1 研究目标200字左右
当前中国城市研究依赖的宏观人口普查或静态网格密度数据，存在缺乏微观个体社会经济属性与精细化时空属性的核心局限，制约了城市复杂机制揭示与动态城市数字孪生构建。本课题依托物理启发（多层次扩散）理论，融合多源异构数据，研发精细人口时空化方法，构建兼具微观社会经济属性、高精度地理信息的大尺度城市人口数据库，为动态城市数字孪生建设与城市复杂系统研究提供数据基础。

1.多源数据融合的高精度人口空间化方法研究：针对现有缺乏刻画个体人口的数据问题，研究如何协同宏观人口普查、手机信令、土地利用等多源异构数据，建立基于多层次扩散理论的物理启发模型，生成具有详实地理信息与社会经济属性（如年龄、职业、收入）的合成人口数据库，奠定空间精细化的个体数据基底，为后续人口时空化研究提供核心数据支撑。

国内外文献综述
 从国际研究来看，合成人口技术形成了三种主流技术路线，（1）合成重构（Synthetic Reconstruction, SR）：基于已知的分布数据和小部分微观个体样本，拟合真实个体的各类属性分布，实现人口群体的“重构”。SR方法因对基础真实样本依赖程度低，计算流程简洁、模型拟合准确度高等优点被广泛用于合成人口的研究中，典型算法如IPF，IPU等。其中，由Beckman等人（1996）提出的迭代比例拟合（Iterative Proportional Fitting, IPF）方法是合成人口研究中最受欢迎的核心方法之一，大部分合成人口软件（PopGen, SynthPop等）都会内置该算法。（2）组合优化（Combinatorial Optimization, CO）：基于真实个体样本库，通过复制、组合和替换真实个体的方式，使生成的合成人口与预设的宏观统计约束（如区域年龄结构、家庭规模分布等）的误差最小。经典的适应度匹配算法，如遗传算法、模拟退火算法、爬山算法等都能用于CO中。然而，SR和CO方法在计算过程中都或多或少地依赖真实样本以约束合成样本地属性分布，这对初始数据的要求较高，使得人口数据不丰富的国家或地区难以开展合成人口工作。而且，传统算法会存在“零单元问题”，即无法拟合在初始样本中缺失但在真实人口中存在的属性分布。因此，（3）统计学习（Statistical Learning, SL）在近些年来愈加显示出优异的潜力。借助机器学习算法，该方法能够捕捉变量之间高阶的非线性相关性，挖掘人口属性分布的内在关联规律，直接生成属性逻辑一致、精度更高的个体信息，而无需依赖真实样本以在计算时满足宏观属性分布,。

典型的SL方法有：Sun与Earth（2015）提出基于贝叶斯网络的图形化建模方法（BN，Bayesian Network），通过节点（属性）与边（属性关联）构建人口属性的概率依赖关系图，在样本不全时根据条件概率进行推断，实现多维度属性的协同生成；深度生成模型（DGM）包括 VAE、GAN和扩散模型 (Diffusion Models)。它们并不直接计算概率分布，而是学习如何“创造”数据。
深度生成模型（DGM）为解决传统方法的"零单元问题"提供了新的思路——它们能够生成训练样本中未曾出现但真实存在的属性组合。然而，VAE与GAN等早期深度生成模型在高维人口画像场景下仍面临困境：一方面，模型容易生成逻辑上不可行的组合；另一方面，若将规则约束放在生成之后进行过滤或修补，往往效率低下且可能破坏已学到的属性关联结构。这一困境的根源在于：VAE/GAN采用"一步到位"的生成机制，难以在生成过程中持续满足复杂的多层级约束。
生成式扩散模型（Diffusion Models）为此提供了一条新路径。扩散模型通过"逐步去噪"的迭代过程重建数据分布，使得高维联合分布的估计被分解为多次低难度的局部修正；更关键的是，宏观统计与规则约束可在每个生成步骤中持续注入，使约束满足内嵌于生成过程本身，而非依赖事后修补（Christopher et al., 2024）。这一机制已在近期的合成人口研究中得到初步验证 (Kang et al., 2023; Tang et al., 2025)，表明扩散模型在边际一致性与稀有组合补齐方面优于传统方法，但现有工作主要聚焦于社会经济属性的合成，对建筑物尺度空间锚定与时空动态建模覆盖尚不充分。
基于上述分析，本研究提出"基于扩散的多层次人口生成方法"，将人口画像的高维联合分布重建分解为"由粗到细"的多层级生成流程——先生成区域/家庭层面的宏观结构，再在其约束下生成个体属性与建筑物尺度落点——并在生成过程中持续融入普查边际、建筑物/POI空间条件与时间动态约束，实现"属性—空间—时间"联合分布的一体化生成与约束满足。
相较于国际研究，国内关于合成人口画像的系统性研究起步较晚，研究成果相对有限。现有研究主要集中于传统IPF与IPU方法的应用，核心研究场景包括两类：一是对小规模人口出行调查数据进行扩样，生成符合城市宏观统计特征的大规模出行人口画像；二是基于全国人口普查、城市统计年鉴等宏观数据，通过IPF/IPU方法匹配部分城市的个体与家庭微观数据，构建区域性合成人口数据库。总体而言，由于样本的限制，国内研究尚未充分涉及人口合成的深度应用，对国际上常用的合成人口方法，尤其是机器学习模型的探索不足，缺乏实现精细化人口画像的技术手段。与之相对的，国内对实现人口空间化信息的研究较多。人口空间化,是基于人口空间分布模型或采用一定的计算方法或算法,对人口统计数据进行离散化处理,发掘并展现其中隐含的空间信息,以模拟或再现客观世界的人口地理分布，与人口画像再现客观世界人口属性分布不同。二者的结合能够帮助我们既确定人口的真实地理信息，又确定人口的真实属性信息，打造最精确的合成人口数据库。
人口空间化的研究有着从单一数据到多源数据，从插值算法到机器学习的发展过程。早期学者们利用人口统计数据和行政区域地理边界数据进行空间插值，原理为假设人口在格网内均匀分布，根据格网的面积与人口密度数据，将人口数据信息由行政单元转化为地理网格单元，典型方法如负指数模型、核密度估计法、协同克里金法等。空间插值法可以实现人口分布密度表现形式从统计数据到地理空间图像的格式转变，但无法刻画真实人口分布。发展后的人口空间化研究则利用遥感和GIS建立地理信息和人口统计数据间的多元回归关系，以土地利用、地形地貌、夜间灯光、多分辨率影像等多种参考因素及人口分布数据在各地理空间网格逐格点计算。在此基础之上，多源数据的使用能够极大提升人口空间化的精度，可以从几十千米的尺度到几百米的尺度。主要方法为对各单因素赋予不同权重方案进行加权(乘积)融合，以获取各格网单元人口分布系数，进而计算各网格的人口分布数据。
建筑物特征被认为可以为更加精细尺度的人口估算提供最直接的物理约束。结合机器学习算法，人口空间分布数据可以实现百米量级的突破。比如，将随机森林模型应用于街景影像（SVI）和POI数据可生成武汉市100m x 100m尺度的人口空间化分布。
近年来移动通信的发展使得人口空间分布计算有了新的分时数据源，也具有了人口空间化方法突破为人口时空化方法的可能。通过对移动通讯信令的分析，可以得到精细时空尺度上的人口分布情况，比如上海市公里格网级每小时人口密度图谱。上述研究佐证了通过多源数据，尤其是结合移动信令数据后可以开发在建筑物尺度上合成带有精细时空属性的人口数据库的方法。
基于上述调研，我们将提出一个在建筑物尺度上融合多源大数据来进行人口精细化时空生成的方法。
    经过空间化处理的数据可与资源环境数据、社会调查数据、经济统计数据等多源数据进行融合，可以更好地为城市规划、经济决策、灾害预防、犯罪管理等研究提供辅助决策。将人口分布和人口画像的结合可以提供最准确的人口信息数据，国内现有成果在生成精细化人口时空数据和人口画像数据上还存在技术突破空间，且尚未有研究将人口时空信息和人口画像信息予以整合，本研究正是回应了这一关切。

    我国城镇化正从快速增长期转向稳定发展期，城市发展正从大规模增量扩张阶段转向存量提质增效为主的阶段。从物质的增长到关注人的需求，从重视项目、投资和经济，转向城市的社会治理，这是城市增长方式、增长动力的巨大转变。早在2015年，习总书记就在中央城市工作会议颇具前瞻性地指出，城市的核心是人，关键是人的衣食住行、生老病死和安居乐业。而人口统计是城市长期发展的基础性、战略性支撑，是制定国民经济社会发展规划、完善新时代人口发展战略、优化城市公共资源配置的核心依据。国内现有的人口统计体系以“普查+抽样+行政记录”为核心架构，虽然能够保障人口基础信息的宏观覆盖，但仍然存在普查周期偏长、人口数据空间精度与时效性不足、调查实施成本高昂等问题，与城市建设对人口统计“实时性、精细化、全周期追踪”的核心需求存在错配。随着国家对城市数智化转型与精细化管理的战略部署持续深化，2025年中央城市工作会议明确提出，我国城市建设要坚持以城市居民需求为导向，顺应数智化趋势，不断提升城市治理智慧化和精细化水平。这一战略需求，对构建高精度、动态化的人口基础数据库提出了更为迫切的现实挑战。

深度生成模型（DGM）为解决传统方法的"零单元问题"提供了新的思路——它们能够生成训练样本中未曾出现但真实存在的属性组合。然而，VAE与GAN等早期深度生成模型在高维人口画像场景下仍面临困境：一方面，模型容易生成逻辑上不可行的组合；另一方面，若将规则约束放在生成之后进行过滤或修补，往往效率低下且可能破坏已学到的属性关联结构。这一困境的根源在于：VAE/GAN采用"一步到位"的生成机制，难以在生成过程中持续满足复杂的多层级约束。
生成式扩散模型（Diffusion Models）为此提供了一条新路径。扩散模型通过"逐步去噪"的迭代过程重建数据分布，使得高维联合分布的估计被分解为多次低难度的局部修正；更关键的是，宏观统计与规则约束可在每个生成步骤中持续注入，使约束满足内嵌于生成过程本身，而非依赖事后修补（Christopher et al., 2024）。这一机制已在近期的合成人口研究中得到初步验证 (Kang et al., 2023; Tang et al., 2025)，表明扩散模型在边际一致性与稀有组合补齐方面优于传统方法，但现有工作主要聚焦于社会经济属性的合成，对建筑物尺度空间锚定与时空动态建模覆盖尚不充分。
基于上述分析，本研究提出"基于扩散的多层次人口生成方法"，将人口画像的高维联合分布重建分解为"由粗到细"的多层级生成流程——先生成区域/家庭层面的宏观结构，再在其约束下生成个体属性与建筑物尺度落点——并在生成过程中持续融入普查边际、建筑物/POI空间条件与时间动态约束，实现"属性—空间—时间"联合分布的一体化生成与约束满足。
